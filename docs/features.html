ACUTE WEB / FEATURES

Familiar essentials.
A clear point of view.

One product identity, with native engines and interfaces on Android, iPhone and iPad. Availability and behavior vary by platform.

EVERYDAY BROWSING

The essentials, thoughtfully arranged.

Tabs, bookmarks, history and downloads give you a familiar foundation, with controls built for the platform in your hand.

PRIVATE SPACES

Keep a private session private.

Both projects include private browsing. On iOS, private tabs use non-persistent website storage and are excluded from saved sessions and history.

ANDROID

Gecko, with room to make it yours.

Compatible browser extensions, saved passwords and larger-screen layouts. Signed APKs are available for ARM64 and x86_64 devices.

IPHONE & IPAD

Native to Apple platforms.

A SwiftUI interface powered by WebKit, with tab/address capsules, bookmarks, downloads and keyboard shortcuts. Available as a sideload-only beta.

CONTROL

A clear focus on privacy.

Acute disables its telemetry and automatic diagnostic uploads. On iOS, per-site controls include tracker blocking, JavaScript, media capture and local website data.

OPEN DEVELOPMENT

See how it is built.

Follow the code and development in the Android and iOS repositories. Report problems, read release notes and examine the implementation for yourself.
