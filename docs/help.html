A little help
getting started.

Downloads, installation notes and the right place to find support.

Install on Android.

Open the stable release page and choose the signed APK for your device’s architecture: ARM64 or x86_64. Follow Android’s installation prompts. Acute is distributed directly, outside Google Play.

The Android app includes update checks that direct you to a newer release and hand installation to Android’s package installer.

Try the iPhone and iPad beta.

The iOS project is a sideload-only beta. There is no App Store or TestFlight build. The IPA must be signed before installation.

Start with the iOS releases and follow the installation and release notes for the current build.
